# 고객별 자료 요청 관리 서비스

## 서비스의 목적

고객별 자료 요청, 제출 여부, 마감일을 한곳에서 관리한다.

## 최종 모습

첫 화면에서 오늘의 업무 현황을 보고, 지연된 고객과 고객별 요청 자료를 바로 확인한다.

```text
ClientFlow

오늘 현황
──────────────────────
전체 고객    42
진행중       15
지연          5
완료         22

[지연 고객만 보기]

ABC상사
마감: 9/18
진행률: 2 / 4

제출 완료  카드 사용내역
제출 완료  매입매출 자료
미제출     급여대장
미제출     통장내역

[AI 요청문 생성]
```

AI 요청문 생성 버튼을 누르면, 아직 제출되지 않은 자료를 바탕으로 고객에게 보낼 문구 초안을 만든다.

```text
ABC상사에서 아직 제출하지 않은 자료

- 급여대장
- 통장내역

↓

안녕하세요.
ABC상사 세무 업무와 관련하여
급여대장과 통장내역이 아직 확인되지 않아
전달 부탁드립니다.
```

## 최종 기능

1. 고객을 등록, 수정, 삭제한다.
2. 고객별 요청 자료를 관리한다.
3. 자료 제출 여부를 확인한다.
4. 마감일과 지연된 고객을 관리한다.
5. 전체 업무 현황을 한눈에 본다.
6. 기존 엑셀 또는 CSV 고객 자료를 가져온다.
7. AI로 고객 요청문 초안을 만든다.
8. 지연 고객을 찾아 반복 업무를 줄인다.
