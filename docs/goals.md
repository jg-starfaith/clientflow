# 고객별 자료 요청 관리 서비스

## 서비스의 목적

고객별 자료 요청, 제출 여부, 마감일을 한곳에서 관리한다.

## 이 서비스에서 할 수 있는 일

- 고객을 추가한다.
- 고객별 자료 요청과 제출 상태를 관리한다.
- 마감일과 지연된 자료를 확인한다.
- 엑셀 또는 CSV 파일로 고객 목록을 가져온다.
- 전체 업무 현황을 확인한다.
- 고객에게 보낼 자료 요청 문구를 만든다.
- 자주 쓰는 자료 요청을 묶음으로 저장해 반복 업무를 줄인다.

## 이번에는 만들지 않는 일

- 로그인과 권한 관리
- 결제
- 실제 문자 또는 이메일 발송
- 모바일 앱
- 여러 언어 지원
